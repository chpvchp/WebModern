# 🧭 LEVEL 0 — Absolute Beginner (Chưa biết gì / mới vào nghề)

## 🎯 Mục tiêu cơ bản

* Hiểu web là gì
* Biết HTML/CSS/JS cơ bản
* Biết chạy project React và FastAPI mẫu

## 🚀 Mục tiêu nâng cao

* Biết sửa UI đơn giản
* Biết gọi API đơn giản bằng fetch/axios

## 🎨 Frontend có gì

* HTML cơ bản (div, form, input)
* CSS cơ bản (margin, padding, flex)
* JavaScript cơ bản:

  * biến, hàm, array, object
* React:

  * component
  * props
  * useState (rất cơ bản)

## ⚙️ Backend có gì

* Khái niệm API là gì
* FastAPI hello world:

  * GET endpoint
* JSON response

## 🧰 Công cụ cần

* VS Code
* Node.js
* Python 3.10+
* Postman / Thunder Client
* Git (cơ bản)

## 🧠 Cần nắm vững

* HTTP request/response
* JSON là gì
* Client vs Server

# 🧭 LEVEL 1 — Beginner Web App

## 🎯 Mục tiêu cơ bản

* Làm được web CRUD đơn giản
* Kết nối frontend + backend

## 🚀 Mục tiêu nâng cao

* Hiểu flow dữ liệu fullstack

## 🎨 Frontend

* React:

  * useEffect
  * fetch API
  * component structure
* Tailwind CSS:

  * flex, grid
  * spacing, color
* Form đơn giản (input, submit)

## ⚙️ Backend

* FastAPI:

  * POST / GET / PUT / DELETE
* Pydantic model
* CORS setup

## 🧰 Công cụ

* Axios
* FastAPI Uvicorn
* SQLite (tạm thời)

## 🧠 Cần nắm

* CRUD là gì
* REST API
* State + props flow

# 🧭 LEVEL 2 — Junior Fullstack

## 🎯 Mục tiêu cơ bản

* Làm project full CRUD có database thật

## 🚀 Mục tiêu nâng cao

* Tách frontend/backend rõ ràng
* Biết structure project chuẩn

## 🎨 Frontend

* React Router (multi-page SPA)
* Layout system
* Loading / error state
* Form validation cơ bản

## ⚙️ Backend

* PostgreSQL
* SQLAlchemy ORM
* Repository pattern (basic)
* Auth cơ bản (JWT intro)

## 🧰 Công cụ

* PostgreSQL
* Alembic (migrate)
* dotenv

## 🧠 Cần nắm

* SPA là gì
* ORM vs raw SQL
* Authentication basic flow

# 🧭 LEVEL 3 — Intermediate Fullstack (Production-ready mindset)

## 🎯 Mục tiêu cơ bản

* Build app có auth + database + deploy được

## 🚀 Mục tiêu nâng cao

* Code sạch, có structure

## 🎨 Frontend

* React advanced:

  * Context API
  * custom hooks
  * protected routes
* Tailwind:

  * component design system
* UX:

  * skeleton loading
  * toast notification

## ⚙️ Backend

* FastAPI advanced:

  * JWT authentication full
  * refresh token
  * dependency injection
* PostgreSQL:

  * relationships (1-1, 1-n, n-n)
* Pagination + filter API

## 🧰 Công cụ

* Docker (basic)
* Redis (cache basic)
* Git branching workflow

## 🧠 Cần nắm

* Authentication flow chuẩn (access/refresh token)
* Clean architecture basics
* API design chuẩn REST

# 🧭 LEVEL 4 — Advanced Fullstack Engineer

## 🎯 Mục tiêu cơ bản

* Build hệ thống giống production real company

## 🚀 Mục tiêu nâng cao

  * websocket (real-time)
* PostgreSQL:

  * indexing
  * query optimization
* Microservices intro

## 🧰 Công cụ

* Docker compose
* Nginx
* CI/CD basics (GitHub Actions)

## 🧠 Cần nắm

* Performance bottleneck
* System design basic
* Caching strategy

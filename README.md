# Modern Web Learning Project

Learning modern fullstack web development with:

- React
- Tailwind CSS
- Vite
- FastAPI

## Goals

- Learn modern frontend architecture
- Build backend APIs with FastAPI
- Build database basic with PostgreSQL
- Connect frontend and backend, backend and database
- Learn Git and GitHub workflow
